# Replit build brief - Nick O portfolio

Build a polished, responsive personal engineering portfolio for Nick Osborn ("Nick O" publicly), aimed at Forward Deployed Engineer and AI Solutions hiring teams.

Use React, TypeScript, Vite and Tailwind CSS. Read project Markdown/frontmatter from `content/projects/` and JSON from `content/skills.json` and `content/experience.json` at build time; do not hardcode content into components. Design a restrained dark interface with clear typography, teal accents, accessible mobile layout and minimal animation. Include a homepage, featured project cards, case-study detail pages, experience, skills, about and configurable contact links. No backend, CMS, authentication or database. Ensure the static site can deploy from GitHub to Cloudflare Pages or Vercel.

Each case study should explain the problem, Nick's personal contribution, technical approach and outcome. Do not invent metrics, links, screenshots or contact details. Keep employer/client-sensitive entries as drafts until approved. Do not imply Nick personally wrote every line of AI-generated code or claim advanced Python skills. Document setup/build commands, and commit the implementation to this repository.
